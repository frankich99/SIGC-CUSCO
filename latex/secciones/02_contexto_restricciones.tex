\section{Contexto del proyecto y restricciones}

El proyecto cuenta con un plazo estricto de \textbf{dos semanas} de desarrollo (iniciado el 22 de octubre de 2026), trabajado por tres estudiantes de la UNSAAC a tiempo parcial. Para cumplir con el tiempo, se seleccionaron herramientas estables y un flujo de trabajo ágil y ordenado.

\subsection{Tecnologías utilizadas}

\begin{itemize}[nosep]
    \item \textbf{Backend:} \textbf{Laravel 13} con \textbf{PHP 8.4}. Se usa para el manejo de rutas, controladores, validación de datos en formularios y el ORM Eloquent para comunicarse con la base de datos.
    \item \textbf{Base de Datos:} \textbf{MySQL 8.0} (motor InnoDB). Garantiza que los cupos no se dupliquen y mantiene la relación entre usuarios, cursos y notas mediante claves foráneas.
    \item \textbf{Frontend:} Plantillas \textbf{Blade} y estilos con \textbf{Tailwind CSS}, asegurando que la interfaz funcione bien tanto en computadoras como en celulares.
    \item \textbf{Gestión del proyecto:} \textbf{Jira Software}. Tablero ágil para organizar el backlog, asignar tareas y medir el avance del equipo.
    \item \textbf{Control de versiones y pruebas:} \textbf{GitHub} para el control de cambios mediante Pull Requests y \textbf{PHPUnit} para ejecutar pruebas automáticas.
\end{itemize}
